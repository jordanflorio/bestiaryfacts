Privacy Policy

Effective 26 July 2026

The short version: this website collects nothing, and our publishing tool has no users other than the channel operator, so it holds no data about anybody else.

What Bestiary Publisher is

Bestiary Publisher is private software used by the operator of The Bestiary (@bestiaryfacts) to upload The Bestiary's own videos to The Bestiary's own social media accounts through each platform's official API. It is not a public product. There is no sign-up, no account system, and no third-party users.

Information we collect

  • This website: informational only. It sets no cookies, runs no analytics, and collects no personal data. It is hosted on GitHub Pages, which may perform standard technical logging (such as IP addresses in server logs) outside our control.
  • Bestiary Publisher: it does not access, collect, or store any data about any third-party user. It reads the channel operator's own video files and caption text from the operator's own computer and sends them to the platform the operator is publishing to.
  • Credentials: the tool stores API keys and OAuth tokens for the channel's own accounts in a local configuration file on the operator's machine. These are used only to authenticate to those same accounts.

Information we share

Nothing is sold, rented, or shared. Credentials and video content are transmitted only to the official API of the platform being published to (for example YouTube, TikTok, Instagram, or X), and nowhere else. There are no advertising networks, data brokers, or third-party trackers involved.

Data retention and deletion

Credentials are kept only while they are in use and can be revoked at any time by the account owner from the relevant platform's own settings — revoking access immediately ends the tool's ability to act on that account. Local credential files can be deleted by the operator at any time. We hold no third-party personal data, so there is none to retain or delete.

Children's privacy

Neither this website nor Bestiary Publisher is directed to children, and we do not knowingly collect any information from children.

Changes

We may update this policy. Changes take effect when posted here, and the effective date above is updated to match.
